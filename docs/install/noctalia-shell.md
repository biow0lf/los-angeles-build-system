# Noctalia Shell v5

## Installation

### Default noctalia shell

```shell
apk add noctalia umbriel noctalia-greeter
```

Instead of `umbriel` (noctalia wayland compositor), can be used:
labwc or mango.

### Noctalia with labwc

```shell
apk add noctalia labwc noctalia-greeter
```

### Noctalia with mango

```shell
apk add noctalia mangowm noctalia-greeter
```
