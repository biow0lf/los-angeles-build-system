# Unfriendly Linux

## Description

Simple desktop linux.

## Features

* glibc based
* with systemd
* x86_64 only (for now?)
* apk as package manager
* apko + melange
* builded by AI
* fixed by humans
* vanilla packages with minimal patches
* Noctalia Shell v5 (with umbriel or labwc wayland compositor)
